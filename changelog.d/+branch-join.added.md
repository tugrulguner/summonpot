Current source supports fully resolved required `Exactly(1)` branches and joins through existing `Operation`, `FromResult` and `after` declarations. A private stable topological order executes sequentially through the shared guarded kernel without resolving a model, with a Pydantic request/response, at least one request binding and one exact terminal response producer. This does not add a public graph API, parallel scheduling, choice-bearing graphs, broader repetition, rollback or durable recovery. Published v0.14.0 is unchanged.
